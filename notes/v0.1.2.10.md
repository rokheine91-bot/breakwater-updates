# Tsunami Defense 0.1.2.10

New in 0.1.2.10:
- Fixed the light vertical streaks in deep water (a drawing bug: small gaps between particles restarted the depth colour).
- Fixed hitches (frames of 60-130 ms): the game used every logical core and starved Windows and its own render thread. It now uses one thread per physical core minus one.
- Firmer water: the pressure solver works more precisely again (costs a little speed, multigrid keeps it cheap).

From 0.1.2.9: multigrid pressure solver, F5 benchmark (your result: 5.5 ms average, target 8 ms).
