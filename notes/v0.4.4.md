# Tsunami Defense 0.4.4 (test build: less work around the water)

- The houses and the water now only exchange data in the area around the houses (was the whole land, mostly empty sky).
- The houses picture is only redrawn when something about the houses changed.
- Cheaper statistics every frame.
- VSync "on" is now adaptive: when a frame is late the game no longer waits for the next screen refresh (that turned 20 ms frames into 33 ms ones).
- Calm start screen on the workstation: 31-33 fps -> 39 fps. The performance log (F12 reports) now shows where every millisecond of a frame goes.
