# Tsunami Defense 0.1.2.1

New in 0.1.2.1:
- Settings window (Esc or the Settings button): display mode (windowed, borderless or exclusive fullscreen), window size including 21:9 sizes, widescreen, pixel scaling, antialiasing, VSync, max FPS, water look, show stats. Settings are saved and kept across updates.
- Widescreen: the game fills any screen (16:9, 21:9, 32:9...) with no black bars. The level stays the same size and centred; wider screens show more around it. Black bars are an option.
- Fixed: water ran too fast on high refresh rate screens (e.g. 2.4x at 144 Hz). It now always runs at real speed.

From 0.1.2:
- Water is about 5x faster (all CPU cores, only computes where water is). Identical results on every PC.
- Water is one blue; each particle has a faint white outline (O switches to solid blue).
- Ctrl + left mouse removes water, Ctrl + right mouse removes concrete, mouse wheel changes brush size, Square/Circle brush (or B).

Known limits:
- All graphics are placeholders.
- Antialiasing softens pixel art; Off is recommended.
