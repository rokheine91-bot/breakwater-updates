# Tsunami Defense 0.1.2.5

New in 0.1.2.5 - automatic bug reports:
- After a crash, the next start makes a bug report by itself and sends it to the developer.
- The first serious error in a session also makes and sends a report automatically.
- F12 makes and sends a report at once.
- A report holds both session logs, the game state and a screenshot. If sending fails (offline), it is kept and sent on a later start.

From 0.1.2.4: crash fix, logger (%APPDATA%\TsunamiDefense\logs), F3 debug overlay.
From 0.1.2.3: realistic water look (O switches).
From 0.1.2.2: water keeps its volume (D switches the fix).
From 0.1.2.1 / 0.1.2: settings (Esc), widescreen, real-time speed, faster solver, brush tools.
