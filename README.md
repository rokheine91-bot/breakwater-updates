# Tsunami Defense - updates

This repository hosts the installer and game updates for **Tsunami Defense** (code name Breakwater).

**Install:** download `installer/TsunamiDefenseSetup.zip`, unzip it and run `TsunamiDefenseSetup.exe` once. It installs the game to `%LOCALAPPDATA%\TsunamiDefense`, creates desktop and Start menu shortcuts, and on every start checks for a new version, shows the patch notes and asks before updating.

Windows may warn about an unknown publisher (the installer is not signed yet): choose "More info" and "Run anyway".
